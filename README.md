# AlbumPaper-Plus

A system tray app that changes your desktop wallpaper based on the track you are listening to. Works with Spotify or Last.fm. An internet connection is required.

AlbumPaper-Plus is a fork of **[AlbumPaper](https://github.com/jac0b-w/AlbumPaper) by [jac0b-w](https://github.com/jac0b-w)**, based on upstream release **v4.1.0**. The original project, its design and most of the code are the work of jac0b-w. This fork adds the features listed below. See [CHANGELOG.md](CHANGELOG.md) for the full list of modifications.

## What this fork adds

- **Weekly top-tracks wallpaper (Spotify).** Once a week the default wallpaper is replaced with album art picked from your Spotify top tracks. Albums are chosen at random, weighted toward your higher-ranked tracks. Requires the `user-top-read` scope, which is requested on login.
- **Pure-Python render fallback.** If the compiled Rust module is not present, wallpapers are generated by `albumpaper/albumpaper_rs.py` using Pillow and opensimplex (colored noise backgrounds).
- **Better palette selection.** Colours are picked by a brightness-weighted vibrancy score, which ignores dark and pale noise.
- **Album art cache.** Downloaded album art is cached locally.
- **Linux desktop support (GNOME).** Sets the wallpaper (and optionally the lock screen) through `gsettings`, and syncs light/dark mode and the accent colour to the album art. The sync option is only shown on Linux.
- **Spotify rate limiting.** Respects `Retry-After` on HTTP 429 responses and throttles API calls.
- **Startup helpers** for Windows (`add_to_startup.ps1`, `setup_global_command.ps1`) and Linux (`add_to_startup.sh`, `setup_global_command.sh`).

Not in this fork: the Windows accent-colour sync (the option is hidden on Windows) and the mini player with lyrics.

## Setup

1. Install Python 3 and the dependencies: `pip install -r requirements.txt`
2. Create a Spotify app at the Spotify developer dashboard and add `http://127.0.0.1:8080/` as a redirect URI. The upstream wiki has a walkthrough: [Getting API Keys](https://github.com/jac0b-w/AlbumPaper/wiki/Getting-API-Keys).
3. Copy `albumpaper/services.ini` values (`client_id`, `client_secret`) or, for development, copy it to `albumpaper/services-dev.ini`. Both are git-ignored so your keys are never committed.
4. Start the app:
   - Windows: run `AlbumPaper-Plus.bat`
   - Linux: create a virtual environment at `.venv` in the project folder, then run `./AlbumPaper-Plus.sh`
5. Right-click the tray icon, open Settings, pick a service and save. Log in to Spotify when the browser opens.
